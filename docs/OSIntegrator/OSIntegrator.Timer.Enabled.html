Таймер.Активен (Timer.Enabled) Свойство

Использование

Только чтение.

Значение

Тип: Булево.

Возвращает признак активности таймера.

Примечание

Пример

Если Таймер2.Активен Тогда
	Таймер2.Остановить();
КонецЕсли;
