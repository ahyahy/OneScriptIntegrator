Конструктор

НаблюдательФайловойСистемы (FileSystemWatcher) Конструктор Используйте метод ИнтеграторОдноСкрипта.НаблюдательФайловойСистемы (OneScriptIntegrator.FileSystemWatcher) для создания нового экземпляра класса НаблюдательФайловойСистемы (FileSystemWatcher).

Свойства

ВключаяПодкаталоги (IncludeSubdirectories) Возвращает или задает значение, указывающее, следует ли отслеживать подкаталоги в указанном пути. Истина - вы хотите отслеживать подкаталоги, Ложь - в противном случае. Значение по умолчанию: Ложь.
КомпонентДоступен (EnableRaisingEvents) Возвращает или задает значение, определяющее, доступен ли данный компонент. Истина - компонент доступен, Ложь - в противном случае. Значение по умолчанию: Ложь.
Путь (Path) Возвращает или задает путь отслеживаемого каталога. По умолчанию используется пустая строка (""). Это свойство должно быть задано до того, как компонент будет запущен для отслеживания.
РазмерВнутреннегоБуфера (InternalBufferSize) Возвращает или задает размер (в байтах) внутреннего буфера. Размер внутреннего буфера. Значение по умолчанию - 8192 (8K).
Фильтр (Filter) Возвращае или задает строку фильтра, используемую для определения файлов, контролируемых в каталоге. Строка фильтра. По умолчанию используется "*.*" (для всех файлов.)
ФильтрУведомлений (NotifyFilter) Значения перечисления ФильтрыУведомления (NotifyFilters). Значение по умолчанию - побитовая комбинация значений ПоследняяЗапись (LastWrite), ИмяФайла (FileName), и ИмяКаталога (DirectoryName).
