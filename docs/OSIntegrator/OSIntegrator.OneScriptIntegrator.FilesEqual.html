ИнтеграторОдноСкрипта.ФайлыРавны (OneScriptIntegrator.FilesEqual) Метод

Синтаксис

ФайлыРавны(<Путь1>, <Путь2>)

Параметры

Путь1 (обязательный)
Тип: Строка.
Путь до первого сравниваемого файла.
Путь2 (обязательный)
Тип: Строка.
Путь до второго сравниваемого файла.

Возвращаемое значение

Тип: Булево.

Описание

Сравнивает два файла побайтово. Возвращает Истина, если файлы равны.

Примечание

Пример

Сообщить("ФайлыРавны = " + ИОС.ФайлыРавны(ПервыйФайлПуть, ВторойФайлПуть));
