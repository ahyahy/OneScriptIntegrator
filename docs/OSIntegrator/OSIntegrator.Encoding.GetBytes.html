Кодировка.ПолучитьБайты (Encoding.GetBytes) Метод

Синтаксис

ПолучитьБайты(<КодируемаяСтрока>)

Параметры

КодируемаяСтрока (обязательный)
Тип: Строка.
Строка для кодирования.

Возвращаемое значение

Тип: Массив.

Массив, содержащий кодированное представление параметра КодируемаяСтрока.

Описание

Кодирует указанную строку в массив байтов. Байтовые значения переводятся в целые числа.

Примечание

Пример

Кодировка1 = ИОС.Кодировка();
Массив = Кодировка1.ПолучитьБайты("Откуда мне знать?");
Стр = "|";
Для А = 0 По Массив.ВГраница() Цикл
	Стр = Стр + Массив.Получить(А) + "|";
КонецЦикла;
Сообщить(Стр);
