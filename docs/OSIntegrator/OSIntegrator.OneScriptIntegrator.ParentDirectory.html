ИнтеграторОдноСкрипта.РодительскийКаталог (OneScriptIntegrator.ParentDirectory) Метод

Синтаксис

РодительскийКаталог(<Путь>)

Параметры

Путь (обязательный)
Тип: Строка.

Возвращаемое значение

Тип: Строка.

Путь каталога для указанного пути.

Описание

Возвращает сведения о каталоге для указанного пути.

Примечание

Пример

РодительскийКаталог1 = ИОС.РодительскийКаталог(ПутьДоФайла);
Полный пример кода 



ПодключитьВнешнююКомпоненту(ОбъединитьПути(Новый Файл(ТекущийСценарий().Источник).Путь, "OneScriptIntegrator.dll"));
ИОС = Новый ИнтеграторОдноСкрипта();

ПутьДоФайла = ОбъединитьПути(ИОС.КаталогСценария(ЭтотОбъект), ИОС.СлучайноеИмя + ".os");
Сообщить("ПутьДоФайла = " + ПутьДоФайла);
РодительскийКаталог1 = ИОС.РодительскийКаталог(ПутьДоФайла);
Сообщить("Каталог выше = " + РодительскийКаталог1);
РодительскийКаталог2 = ИОС.РодительскийКаталог(РодительскийКаталог1);
Сообщить("Каталог выше = " + РодительскийКаталог2);
