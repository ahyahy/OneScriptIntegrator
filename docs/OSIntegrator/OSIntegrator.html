Библиотека OneScriptIntegrator

Классы

АргументыСобытия (EventArgs) Представляет класс, содержащий данные событий.
Действие (Action) Задает делегат для выполнения метода в другом объекте.
ИнтеграторОдноСкрипта (OneScriptIntegrator) Представляет класс с методами упрощения взаимодействия и обмена данными между сценариями.
ИнформацияЗапускаПроцесса (ProcessStartInfo) Определяет набор значений, используемых при запуске процесса.
Кодировка (Encoding) Представляет кодировку символов.
Математика (Math) Предоставляет константы и статические методы для тригонометрических, логарифмических и других общих математических функций.
НаблюдательФайловойСистемы (FileSystemWatcher) Ожидает уведомления файловой системы об изменениях и инициирует события при изменениях каталога или файла в каталоге.
Процесс (Process) Предоставляет доступ к локальным и удаленным процессам и позволяет запускать и останавливать локальные системные процессы.
Таймер (Timer) Создает событие после заданного интервала с возможностью создания повторяющихся событий.
