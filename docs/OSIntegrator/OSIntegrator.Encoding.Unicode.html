Кодировка.Юникод (Encoding.Unicode) Свойство

Использование

Только чтение.

Значение

Тип: Кодировка (Encoding).

Возвращает кодировку для формата UTF-16 с прямым порядком байтов.

Примечание

Пример

Сообщить("Юникод = " + ИОС.Кодировка().Юникод);
Полный пример кода 



ПодключитьВнешнююКомпоненту(ОбъединитьПути(Новый Файл(ТекущийСценарий().Источник).Путь, "OneScriptIntegrator.dll"));
ИОС = Новый ИнтеграторОдноСкрипта();

Сообщить("Юникод = " + ИОС.Кодировка().Юникод);
