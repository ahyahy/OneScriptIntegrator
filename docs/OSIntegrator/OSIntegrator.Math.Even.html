Математика.Четное (Math.Even) Метод

Синтаксис

Четное(<ЧисловойПараметр>)

Параметры

ЧисловойПараметр (обязательный)
Тип: Число.
Значение, проверяемое на четность.

Возвращаемое значение

Тип: Булево.

Возвращает Истина, если число четное; в противном случае, Ложь. Если в параметре передано не целое число, возвращается Неопределено.

Описание

Возвращает значение, которое показывает, является ли проверяемое число четным.

Примечание

Пример

Сообщить("Четное(82) = " + ИОС.Математика().Четное(82));
Сообщить("Четное(-82) = " + ИОС.Математика().Четное(-82));
Сообщить("Четное(83) = " + ИОС.Математика().Четное(83));
Сообщить("Четное(-83) = " + ИОС.Математика().Четное(-83));
Сообщить("Четное(24.2) = " + ИОС.Математика().Четное(24.2));
