ИнтеграторОдноСкрипта.СообщитьЕслиЛожь (OneScriptIntegrator.ReportIfFalse) Метод

Синтаксис

СообщитьЕслиЛожь(<Условие>, <Сообщение>)

Параметры

Условие (обязательный)
Тип: Булево.
Проверяемое условие.
Сообщение (обязательный)
Тип: Строка.
Текст сообщения.

Возвращаемое значение

Описание

Выводит заключенный в фигурные скобки текст, переданный в параметре Сообщение, если условие, переданное в параметре Условие возвратит Ложь. Метод создан для оптимизации тестирования.

Примечание

Используя метод ИнтеграторОдноСкрипта.СообщитьЕслиЛожь (OneScriptIntegrator.ReportIfFalse) можно получить имитацию исключения в сценарии. Имитация означает, что оповещение об исключении выводится в консоль в том же формате, что и при исключении, с указанием модуля, строки с ошибкой и описания ошибки. Исключением же по сути это не является. Сценарий при этом завершает свою работу с кодом ошибки равном 1.

Пример

ИОС.СообщитьЕслиЛожь(10 = 55, "Здесь ошибка");
