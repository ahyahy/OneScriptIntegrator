ИнтеграторОдноСкрипта.НайтиМежду (OneScriptIntegrator.ParseBetween) Метод

Синтаксис

НайтиМежду(<ИсходнаяСтрока>, <ОтСтроки>, <ДоСтроки>)

Параметры

ИсходнаяСтрока (обязательный)
Тип: Строка.
Строка, в которой производится поиск.
ОтСтроки (необязательный)
Тип: Строка.
Строка, от которой ведем поиск.
ДоСтроки (необязательный)
Тип: Строка.
Строка, до которой ведем поиск.

Возвращаемое значение

Тип: Строка.

Описание

Поиск в строке с указанием левой и правой границ поиска. Возвращается первый найденный по указанным условиям фрагмент. Если фрагмент не найден возвращается Неопределено.

Примечание

Пример

Стр = "Съешь же ещё этих мягких французских булок да выпей чаю";
Стр2 = ИОС.НайтиМежду(Стр, , "зск");
Полный пример кода 



ПодключитьВнешнююКомпоненту(ОбъединитьПути(Новый Файл(ТекущийСценарий().Источник).Путь, "OneScriptIntegrator.dll"));
ИОС = Новый ИнтеграторОдноСкрипта();

Стр2 = ИОС.НайтиМежду(Стр, , "зск");
Стр3 = ИОС.НайтиМежду(Стр, "ещё эт", );

Сообщить(Стр2); // "Съешь же ещё этих мягких францу"
Сообщить(Стр3); // "их мягких французских булок да выпей чаю"
Сообщить(Стр4); // "ё этих мягких французских булок да выпей "
