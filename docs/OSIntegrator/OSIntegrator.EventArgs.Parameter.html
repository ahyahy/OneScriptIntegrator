АргументыСобытия.Параметр (EventArgs.Parameter) Свойство

Использование

Только чтение.

Значение

Тип: Произвольный.

Возвращает объект, заданный при установке обработчика события, для передачи в обработчик события.

Примечание

Пример

Сообщить(ИОС.АргументыСобытия.Параметр.Ключ1);
