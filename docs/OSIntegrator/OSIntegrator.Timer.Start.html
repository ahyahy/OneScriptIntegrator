Таймер.Начать (Timer.Start) Метод

Синтаксис

Начать(<ОбработчикСобытия>, <Интервал>, <Задержка>)

Параметры

ОбработчикСобытия (необязательный)
Тип: Действие (Action).
Возвращает или задает код для выполнения по истечении указанного интервала таймера.
Интервал (необязательный)
Тип: Число.
Время в миллисекундах между отметками таймера. Значение по умолчанию - 0 миллисекунд.
Задержка (необязательный)
Тип: Число.
Время в миллисекундах до запуска таймера. Укажите ноль, чтобы немедленно запустить таймер. Значение по умолчанию - 0 миллисекунд.

Возвращаемое значение

Описание

Запускает Таймер.

Примечание

Пример

Таймер1.Начать();
