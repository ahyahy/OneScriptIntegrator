ИнтеграторОдноСкрипта.ОдноразовыйТаймер (OneScriptIntegrator.OneOffTimer) Метод

Синтаксис

ОдноразовыйТаймер(<Обработчик>, <Интервал>)

Параметры

Обработчик (обязательный)
Тип: Действие (Action).
Обработчик события таймера.
Интервал (обязательный)
Тип: Число.
Время в миллисекундах до срабатывания таймера.

Возвращаемое значение

Описание

Создает событие после заданного интервала, без возможности повторения. Таймер запускается без задержки, сразу после создания.

Примечание

Пример

ИОС.ОдноразовыйТаймер(ИОС.Действие(ЭтотОбъект, "ОбработкаТаймера1"), 2000);
