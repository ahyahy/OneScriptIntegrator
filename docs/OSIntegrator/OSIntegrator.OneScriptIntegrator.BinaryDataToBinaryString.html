ИнтеграторОдноСкрипта.ДвоичныеДанныеВДвоичнуюСтроку (OneScriptIntegrator.BinaryDataToBinaryString) Метод

Синтаксис

ДвоичныеДанныеВДвоичнуюСтроку(<Путь>)

Параметры

Путь (обязательный)
Тип: Строка.
Путь до файла двоичных данных.

Возвращаемое значение

Тип: Строка.

Строка нулей и единиц полученная из двоичных данных.

Описание

Возвращает строку двоичных чисел как результат обработки двоичных данных.

Примечание
