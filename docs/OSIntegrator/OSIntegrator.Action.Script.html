Действие.Сценарий (Action.Script) Свойство

Использование

Чтение и запись.

Значение

Тип: Произвольный.

Возвращает или задает сценарий, в котором будет выполняться делегат.

Примечание

Пример

Сообщить("Сценарий = " + Действие.Сценарий);
