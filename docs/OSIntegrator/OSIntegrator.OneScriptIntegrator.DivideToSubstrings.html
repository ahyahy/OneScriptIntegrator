ИнтеграторОдноСкрипта.РазделитьНаПодстроки (OneScriptIntegrator.DivideToSubstrings) Метод

Синтаксис

РазделитьНаПодстроки(<ИсходнаяСтрока>, <Длина>)

Параметры

ИсходнаяСтрока (обязательный)
Тип: Строка.
Исходная строка.
Длина (обязательный)
Тип: Число.
Длина фрагмента результирующей строки.

Возвращаемое значение

Тип: Строка.

Строка, отформатированная для вставки в код.

Описание

Возвращает строку, разделенную на подстроки определенной длинны, пригодную для использования в коде.

Примечание

Пример

Стр = "Возвращает строку, разделенную на подстроки определенной длинны, пригодную для использования в коде.";
Сообщить("" + ИОС.РазделитьНаПодстроки(Стр, 15));
