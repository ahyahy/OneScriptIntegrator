ИнтеграторОдноСкрипта.ДвоичныеПредставления (OneScriptIntegrator.BinaryRepresentations) Метод

Синтаксис

ДвоичныеПредставления(<НачальноеЧисло>, <КонечноеЧисло>, <ДополнятьНулями>)

Параметры

НачальноеЧисло (обязательный)
Тип: Число.
Начальное число диапазона.
КонечноеЧисло (обязательный)
Тип: Число.
Конечное число диапазона.
ДополнятьНулями (необязательный)
Тип: Булево.
Флаг дополнения строки нулями слева до рассчитанной длины. Значение по умолчанию - Истина.

Возвращаемое значение

Тип: Массив.

Описание

Возвращает в виде массива последовательность целых чисел от параметра НачальноеЧисло до параметра КонечноеЧисло, включительно, переведенных в строковое представление двоичного числа.

Примечание

Пример

М = ИОС.ДвоичныеПредставления(0, 255);
