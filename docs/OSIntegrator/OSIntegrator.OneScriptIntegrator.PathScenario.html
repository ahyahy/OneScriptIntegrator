ИнтеграторОдноСкрипта.ПутьСценария (OneScriptIntegrator.PathScenario) Метод

Синтаксис

ПутьСценария(<Сценарий>)

Параметры

Сценарий (обязательный)
Тип: Произвольный.
Сценарий, путь которого необходимо определить.

Возвращаемое значение

Тип: Строка.

Путь до сценария.

Описание

Возвращает путь до переданного в параметре сценария.

Примечание

Пример

Сообщить("ПутьСценария = " + ИОС.ПутьСценария(ЭтотОбъект));
Полный пример кода 



ПодключитьВнешнююКомпоненту(ОбъединитьПути(Новый Файл(ТекущийСценарий().Источник).Путь, "OneScriptIntegrator.dll"));
ИОС = Новый ИнтеграторОдноСкрипта();

Сообщить("ПутьСценария = " + ИОС.ПутьСценария(ЭтотОбъект));
