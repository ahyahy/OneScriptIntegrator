Синтаксис

ПроброситьИсключение(<Описание>)

Параметры

Описание (обязательный)
Тип: Строка.
Информация для вывода в консоль.

Возвращаемое значение

Описание

Вызывает событие при котором в консоль выводится строка, переданная в параметре. После этого завершается работа сценария с кодом возврата равным 1. Метод создан для оптимизации тестирования.

Примечание

Пример

ИОС.ПроброситьИсключение("ИОС.ПроброситьИсключение из строки 4 / " + ТекущаяДата());
