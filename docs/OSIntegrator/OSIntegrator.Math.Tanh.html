Математика.ГТангенс (Math.Tanh) Метод

Синтаксис

ГТангенс(<Угол>)

Параметры

Угол (обязательный)
Тип: Число.
Угол, измеренный в радианах.

Возвращаемое значение

Тип: Число.

Гиперболический тангенс угла.

Описание

Возвращает гиперболический тангенс заданного угла.

Примечание
