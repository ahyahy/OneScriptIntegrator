ИнтеграторОдноСкрипта.[Перечисление].Количество (OneScriptIntegrator.[Перечисление].Count) Метод

Синтаксис

[Перечисление].Количество()

Возвращаемое значение

Тип: Число.

Описание

Возвращает количество элементов в перечислении.

Примечание

Пример

Стр = "Перечисление ТипыИзмененийНаблюдателя через цикл Для ... По ... Цикл";
Для А = 0 По ИОС.ТипыИзмененийНаблюдателя.Количество - 1 Цикл
	Эл = ИОС.ТипыИзмененийНаблюдателя.Получить(А);
	Стр = Стр + "
	|    Значение = " + Эл + " Имя = " + ИОС.ТипыИзмененийНаблюдателя.Имя(Эл) + " Name = " + ИОС.ТипыИзмененийНаблюдателя.Name(Эл);
КонецЦикла;
Сообщить(Стр);
