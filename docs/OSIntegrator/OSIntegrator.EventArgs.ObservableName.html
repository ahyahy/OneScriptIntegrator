АргументыСобытия.ИмяНаблюдаемого (EventArgs.ObservableName) Свойство

Использование

Только чтение.

Значение

Тип: Строка.

Возвращает имя измененного файла или каталога.

Сообщить("Аргументы.ИмяНаблюдаемого = " + Аргументы.ИмяНаблюдаемого);
