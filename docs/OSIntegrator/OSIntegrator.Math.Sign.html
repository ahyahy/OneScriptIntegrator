Математика.Знак (Math.Sign) Метод

Синтаксис

Знак(<Число>)

Параметры

Число (обязательный)
Тип: Число.
Число со знаком.

Возвращаемое значение

Тип: Число.

Число, которое указывает знак переданного в параметре числа.

Возвращается -1 если значение параметра меньше нуля.

Возвращается 0 если значение параметра равно нулю.

Возвращается 1 если значение параметра больше нуля.

Описание

Возвращает целое число, указывающее знак переданного в параметре числа.

Примечание

Пример

Сообщить("Знак(-55.64) = " + ИОС.Математика().Знак(-55.64));
