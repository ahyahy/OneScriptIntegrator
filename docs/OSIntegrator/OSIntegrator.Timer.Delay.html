Таймер.Задержка (Timer.Delay) Свойство

Использование

Чтение и запись.

Значение

Тип: Число.

Возвращает или задает время в миллисекундах до запуска таймера. Укажите ноль, чтобы немедленно запустить таймер. Значение по умолчанию - 0 миллисекунд.

Примечание

Пример

Таймер2.Задержка = 2300;
