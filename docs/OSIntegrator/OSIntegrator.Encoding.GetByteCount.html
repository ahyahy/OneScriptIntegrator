Кодировка.КоличествоБайтов (Encoding.GetByteCount) Метод

Синтаксис

КоличествоБайтов(<КодируемаяСтрока>)

Параметры

КодируемаяСтрока (обязательный)
Тип: Строка.
Строка для вычисления.

Возвращаемое значение

Тип: Число.

Количество байтов, необходимых для кодирования параметра КодируемаяСтрока.

Описание

Вычисляет количество байтов, необходимых для кодирования указанной строки.

Примечание

Пример

КодируемаяСтрока = "Произвольный текст";
Сообщить("КоличествоБайтов = " + ИОС.Кодировка.ASCII.КоличествоБайтов(КодируемаяСтрока)); // КоличествоБайтов = 18
