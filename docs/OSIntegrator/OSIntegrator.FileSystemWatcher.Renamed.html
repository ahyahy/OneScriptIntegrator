НаблюдательФайловойСистемы.ПриПереименовании (FileSystemWatcher.Renamed) Событие

Использование

Чтение и запись.

Значение

Тип: Действие (Action).

Возвращает или задает код для выполнения при переименовании файла или каталога по заданному пути.

Примечание

Переименование просматриваемого каталога не вызовет уведомления. Уведомления создаются только для записей в просматриваемом каталоге.

Аргументы события

ИмяНаблюдаемого (ObservableName) Возвращает имя измененного файла или каталога.
Отправитель (Sender) Возвращает источник (объект) последнего события.
Параметр (Parameter) Возвращает объект, заданный при установке обработчика события, для передачи в обработчик события.
ПолныйПуть (FullPath) Возвращает полный путь для файла или каталога.
СтароеИмя (OldName) Возвращает старое имя измененного файла или каталога.
СтарыйПолныйПуть (OldFullPath) Возвращает старый полный путь файла или каталога.
ТипИзменения (ChangeType) Возвращает тип произошедшего с каталогом события.
