Кодировка.UTF8 (Encoding.UTF8) Свойство

Использование

Только чтение.

Значение

Тип: Кодировка (Encoding).

Возвращает кодировку для формата UTF-8.

Примечание

Пример

Сообщить("UTF8 = " + ИОС.Кодировка().UTF8.ИмяКодировки);

ИОС = Новый ИнтеграторОдноСкрипта();
