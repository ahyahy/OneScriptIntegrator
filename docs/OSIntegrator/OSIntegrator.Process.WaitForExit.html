Процесс.ОжидатьЗакрытия (Process.WaitForExit) Метод

Синтаксис

ОжидатьЗакрытия(<ВремяОжидания>)

Параметры

ВремяОжидания (необязательный)
Тип: Число.
Время ожидания закрытия процесса в миллисекундах. Значение 0 указывает немедленное возвращение состояния процесса, а значение -1 указывает бесконечное ожидание. Значение по умолчанию - -1.

Возвращаемое значение

Тип: Булево.

Описание

Указывает ждать заданное количество миллисекунд для закрытия процесса.

Примечание

Если процесс не завершается к концу интервала, так как отклонен запрос на завершение, в вызывающую процедуру возвращается Ложь.

Если передать методу 0 (ноль), он вернет Истина только в том случае, если процесс уже завершился; в противном случае он немедленно вернет Ложь.

Пример

Если Не Процесс1.ОжидатьЗакрытия(0) Тогда
	Процесс1.ОтменитьЧтениеВывода();
	Процесс1.Уничтожить();
	Приостановить(1000);
	ИОС.Продолжать = Ложь;
КонецЕсли;
