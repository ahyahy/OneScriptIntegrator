ИнтеграторОдноСкрипта.ОбщаяСтруктура (OneScriptIntegrator.ShareStructure) Свойство

Использование

Только чтение.

Значение

Тип: Структура.

Возвращает объект типа Структура, как глобальное свойство и доступную для изменения во всех подключенных сценариях.

Под подключенными сценариями в данном случае подразумеваются сценарии подключенные методом ИнтеграторОдноСкрипта.ЗагрузитьСценарии (OneScriptIntegrator.LoadScripts).

Структура создается и становится доступной при создании объекта ИнтеграторОдноСкрипта.

Примечание

Пример

ОбщаяСтруктура = ИОС.ОбщаяСтруктура;
Полный пример кода 



ПодключитьВнешнююКомпоненту(ОбъединитьПути(Новый Файл(ТекущийСценарий().Источник).Путь, "OneScriptIntegrator.dll"));
ИОС = Новый ИнтеграторОдноСкрипта();

СлучайноеИмя1 = ИОС.СлучайноеИмя;

Стр = "
|Процедура ПриСозданииОбъекта() Экспорт
|	Сообщить(""" + СлучайноеИмя1 + " ПриСозданииОбъекта() ИмяПродукта = "" + ОбщаяСтруктура.ИОС.ИмяПродукта);
|КонецПроцедуры
|";
КаталогКлассы = ОбъединитьПути(ИОС.КаталогСценария(ЭтотОбъект), "Temp\Классы1");
Если Не Новый Файл(КаталогКлассы).Существует() Тогда
	СоздатьКаталог(КаталогКлассы);
КонецЕсли;
Пока Не Новый Файл(КаталогКлассы).Существует() Цикл
	Приостановить(100);
КонецЦикла;
ИОС.ЗаписатьВесьТекст(ОбъединитьПути(ИОС.КаталогСценария(ЭтотОбъект), "Temp\Классы1" + ПолучитьРазделительПути() + СлучайноеИмя1 + ".os"), Стр);
Приостановить(3000);

ОбщаяСтруктура = ИОС.ОбщаяСтруктура;
ОбщаяСтруктура.Вставить("ИОС", ИОС);
Сценарии = ИОС.ЗагрузитьСценарии(ЭтотОбъект, КаталогКлассы);

Если Не Сценарии.Количество() > 1 Тогда
	ВызватьИсключение("{Ошибка в " + ИОС.ПутьСценария(ЭтотОбъект) + "}");
КонецЕсли;
