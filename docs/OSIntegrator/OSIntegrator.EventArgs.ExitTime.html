АргументыСобытия.ВремяЗакрытия (EventArgs.ExitTime) Свойство

Использование

Только чтение.

Значение

Тип: Дата.

Возвращает время закрытия процесса.

Примечание

Здесь свойство ИОС.АргументыСобытия.ВремяЗакрытия фиксирует время выполнения метода Kill() для процесса.

Пример

Процедура Процесс1_ПриЗакрытии() Экспорт
	Сообщить("Процесс1_ПриЗакрытии " + ТекущаяУниверсальнаяДатаВМиллисекундах());
	Сообщить("ВремяЗакрытия " + ИОС.АргументыСобытия.ВремяЗакрытия);
	ИОС.Продолжать = Ложь;
