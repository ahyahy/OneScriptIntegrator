Кодировка.ИмяWeb (Encoding.WebName) Свойство

Использование

Только чтение.

Значение

Тип: Строка.

Возвращает для текущей кодировки имя, зарегистрированное в IANA (Internet Assigned Numbers Authority).

Примечание

Пример

Сообщить("ИмяWeb = " + ИОС.Кодировка().ASCII.ИмяWeb);
Полный пример кода 



ПодключитьВнешнююКомпоненту(ОбъединитьПути(Новый Файл(ТекущийСценарий().Источник).Путь, "OneScriptIntegrator.dll"));
ИОС = Новый ИнтеграторОдноСкрипта();

Сообщить("ИмяWeb = " + ИОС.Кодировка().ASCII.ИмяWeb);
