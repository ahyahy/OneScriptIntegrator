Процесс (Process) Свойства

Свойства

ВремяНачала (StartTime) Возвращает время запуска процесса.
Дескриптор (Handle) Возвращает собственный дескриптор процесса.
Закрыт (HasExited) Возвращает значение, указывающее, был ли закрыт процесс.
Идентификатор (Id) Возвращает созданный системой уникальный идентификатор процесса.
ИмяПроцесса (ProcessName) Возвращает имя процесса.
НачальнаяИнформация (StartInfo) Возвращает или задает набор значений для передачи их объекту Процесс (Process).
ПотокВывода (StandardOutput) Возвращает поток, используемый для чтения текстовых выходных данных приложения.
