Обзор Процесс (Process)

Конструктор

Процесс (Process) Конструктор Используйте метод ИнтеграторОдноСкрипта.Процесс (OneScriptIntegrator.Process) для создания нового экземпляра класса Процесс (Process).

Свойства

ВремяНачала (StartTime) Возвращает время запуска процесса.
Дескриптор (Handle) Возвращает собственный дескриптор процесса.
Закрыт (HasExited) Возвращает значение, указывающее, был ли закрыт процесс.
Идентификатор (Id) Возвращает созданный системой уникальный идентификатор процесса.
ИмяПроцесса (ProcessName) Возвращает имя процесса.
НачальнаяИнформация (StartInfo) Возвращает или задает набор значений для передачи их объекту Процесс (Process).
ПотокВывода (StandardOutput) Возвращает поток, используемый для чтения текстовых выходных данных приложения.

Методы

Начать (Start) Запускает (или повторно использует) ресурс процесса, определенный свойством Процесс.НачальнаяИнформация (Process.StartInfo) этого компонента Процесс (Process), и связывает его с компонентом.
НачатьЧтениеВывода (BeginOutputReadLine) Начинает асинхронные операции чтения в перенаправленном потоке вывода приложения.
ОжидатьЗакрытия (WaitForExit) Указывает ждать заданное количество миллисекунд для закрытия процесса.
ОтменитьЧтениеВывода (CancelOutputRead) Отменяет асинхронную операцию чтения в перенаправленном потоке вывода приложения.
Уничтожить (Kill) Немедленно останавливает процесс.
