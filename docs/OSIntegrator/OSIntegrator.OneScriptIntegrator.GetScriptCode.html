ИнтеграторОдноСкрипта.ПолучитьКодСценария (OneScriptIntegrator.GetScriptCode) Метод

Синтаксис

ПолучитьКодСценария(<Сценарий>)

Параметры

Сценарий (обязательный)
Тип: Произвольный.
Объект Сценарий.

Возвращаемое значение

Тип: Строка.

Описание

Возвращает код переданного в параметре сценария.

Примечание

Пример

Сообщить("Текст сценария ===");
Сообщить("" + ИОС.ПолучитьКодСценария(ЭтотОбъект));
Сообщить("=== Текст сценария");
Полный пример кода 



ПодключитьВнешнююКомпоненту(ОбъединитьПути(Новый Файл(ТекущийСценарий().Источник).Путь, "OneScriptIntegrator.dll"));
ИОС = Новый ИнтеграторОдноСкрипта();

Сообщить("Текст сценария ===");
Сообщить("" + ИОС.ПолучитьКодСценария(ЭтотОбъект));
Сообщить("=== Текст сценария");

Текст = "// Это текст подключаемого сценария.";
Путь = ОбъединитьПути(ИОС.КаталогСценария(ЭтотОбъект), "Подключаемый сценарий.os");
ИОС.ДобавитьВесьТекст(Путь, Текст);

ПодключитьСценарий(Путь, "МойОбъект");
Сценарий = Новый МойОбъект();

Сообщить("Текст сценария ===");
Сообщить("" + ИОС.ПолучитьКодСценария(Сценарий));
Сообщить("=== Текст сценария");
