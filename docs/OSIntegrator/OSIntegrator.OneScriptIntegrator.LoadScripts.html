ИнтеграторОдноСкрипта.ЗагрузитьСценарии (OneScriptIntegrator.LoadScripts) Метод

Синтаксис

ЗагрузитьСценарии(<Сценарий>, <Каталог>)

Параметры

Сценарий (обязательный)
Тип: Произвольный.
Сценарий, инжектируемый как глобальная переменная в подключаемые сценарии.
Каталог (обязательный)
Тип: Строка.
Каталог поиска сценариев. Если используется обозначение ".\" или "..\" или "./" или "../", поис будет проводиться в каталогах Классы и Модули. Подробнее об этом читайте раздел Библиотеки на сайте односкрипта.

Возвращаемое значение

Тип: Структура.

Структура, содержащая подключенные сценарии. Ключ элемента совпадает с именем файла подключенного сценария (без расширения).

Описание

Находит файлы сценария по указанному пути и подключает их к текущей системе типов инжектируя сценарий из параметра Сценарий как глобальную переменную.

Примечание

Пример

Расположение файлов в примере должно быть следующим:

Сценарии = ИОС.ЗагрузитьСценарии(ЭтотОбъект, КаталогКлассы);
Полный пример кода 



ПодключитьВнешнююКомпоненту(ОбъединитьПути(Новый Файл(ТекущийСценарий().Источник).Путь, "OneScriptIntegrator.dll"));
ИОС = Новый ИнтеграторОдноСкрипта();

СлучайноеИмя1 = ИОС.СлучайноеИмя;
СлучайноеИмя2 = ИОС.СлучайноеИмя;
СлучайноеИмя3 = ИОС.СлучайноеИмя;

Стр = "
|Процедура ПриСозданииОбъекта() Экспорт
|	Сообщить(""" + СлучайноеИмя1 + " ПриСозданииОбъекта() ИмяПродукта = "" + ОбщаяСтруктура.ИОС.ИмяПродукта);
|КонецПроцедуры
|";
КаталогКлассы = ОбъединитьПути(ИОС.КаталогСценария(ЭтотОбъект), "Temp\Классы2");
Если Не Новый Файл(КаталогКлассы).Существует() Тогда
	СоздатьКаталог(КаталогКлассы);
КонецЕсли;
Пока Не Новый Файл(КаталогКлассы).Существует() Цикл
	Приостановить(100);
КонецЦикла;
ИОС.ЗаписатьВесьТекст(ОбъединитьПути(ИОС.КаталогСценария(ЭтотОбъект), "Temp\Классы2" + ПолучитьРазделительПути() + СлучайноеИмя1 + ".os"), Стр);
Приостановить(3000);

Стр = "
|Процедура ПриСозданииОбъекта() Экспорт
|	Сообщить(""" + СлучайноеИмя2 + " ПриСозданииОбъекта()"");
|КонецПроцедуры
|";
ИОС.ЗаписатьВесьТекст(ОбъединитьПути(ИОС.КаталогСценария(ЭтотОбъект), "Temp\Классы2" + ПолучитьРазделительПути() + СлучайноеИмя2 + ".os"), Стр);
Приостановить(3000);

Стр = "
|Процедура ПриСозданииОбъекта() Экспорт
|	Сообщить(""" + СлучайноеИмя3 + " ПриСозданииОбъекта()"");
|КонецПроцедуры
|";
ИОС.ЗаписатьВесьТекст(ОбъединитьПути(ИОС.КаталогСценария(ЭтотОбъект), "Temp\Классы2" + ПолучитьРазделительПути() + СлучайноеИмя3 + ".os"), Стр);
Приостановить(3000);

ОбщаяСтруктура = ИОС.ОбщаяСтруктура;
ОбщаяСтруктура.Вставить("ИОС", ИОС);
Сценарии = ИОС.ЗагрузитьСценарии(ЭтотОбъект, КаталогКлассы);

Для Каждого Эл Из Сценарии Цикл
	Сообщить("======");
	Сообщить("" + Эл.Ключ + " это " + Эл.Значение + ". Путь = " + ИОС.ПутьСценария(Эл.Значение) + "
	|Код сценария " + Эл.Ключ + ":
	|" + ИОС.ПолучитьКодСценария(Эл.Значение));
КонецЦикла;

Если Не Сценарии.Количество() > 1 Тогда
	ВызватьИсключение("{Ошибка в " + ИОС.ПутьСценария(ЭтотОбъект) + "}");
КонецЕсли;
