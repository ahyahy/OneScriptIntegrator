Обзор Таймер (Timer)

Конструктор

Таймер (Timer) Конструктор Используйте метод ИнтеграторОдноСкрипта.Таймер (OneScriptIntegrator.Timer) для создания нового экземпляра класса Таймер (Timer).

Свойства

Активен (Enabled) Возвращает признак активности таймера.
Задержка (Delay) Возвращает или задает время в миллисекундах до запуска таймера. Укажите ноль, чтобы немедленно запустить таймер. Значение по умолчанию - 0 миллисекунд.
Интервал (Interval) Возвращает или задает время в миллисекундах между отметками таймера.
Метка (Tag) Возвращает или задает объект, содержащий дополнительные данные.

Методы

Начать (Start) Запускает Таймер.
Остановить (Stop) Останавливает Таймер.
