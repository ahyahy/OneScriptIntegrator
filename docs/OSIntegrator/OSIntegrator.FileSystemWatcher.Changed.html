НаблюдательФайловойСистемы.ПриИзменении (FileSystemWatcher.Changed) Событие

Использование

Чтение и запись.

Значение

Тип: Действие (Action).

Возвращает или задает код для выполнения при изменении файла или каталога по заданному пути.

Примечание

Событие ПриИзменении (Changed) возникает при изменении размера, системных атрибутов, времени последней записи, времени последнего доступа или разрешений безопасности на файл или каталог в отслеживаемом каталоге.

Аргументы события

ИмяНаблюдаемого (ObservableName) Возвращает имя измененного файла или каталога.
Отправитель (Sender) Возвращает источник (объект) последнего события.
Параметр (Parameter) Возвращает объект, заданный при установке обработчика события, для передачи в обработчик события.
ПолныйПуть (FullPath) Возвращает полный путь для файла или каталога.
ТипИзменения (ChangeType) Возвращает тип произошедшего с каталогом события.

Пример

НаблюдательФайловойСистемы1.ПриИзменении = ИОС.Действие(ЭтотОбъект, "НаблюдательФайловойСистемы1_ПриИзменении");
