Математика.Косинус (Math.Cos) Метод

Синтаксис

Косинус(<Угол>)

Параметры

Угол (обязательный)
Тип: Число.
Угол, измеренный в радианах.

Возвращаемое значение

Тип: Число.

Косинус параметра Угол.

Описание

Возвращает косинус указанного угла.

Примечание

Пример

Сообщить("Косинус(0.9) = " + ИОС.Математика().Косинус(0.9));
