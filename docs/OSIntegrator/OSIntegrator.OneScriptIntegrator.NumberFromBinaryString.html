ИнтеграторОдноСкрипта.ДесятичноеИзДвоичнойСтроки (OneScriptIntegrator.NumberFromBinaryString) Метод

Синтаксис

ДесятичноеИзДвоичнойСтроки(<СтрокаИзНулейЕдиниц>)

Параметры

СтрокаИзНулейЕдиниц (обязательный)
Тип: Строка.
Строка из нулей и единиц.

Возвращаемое значение

Тип: Число.

Описание

Возвращает целое число из представленной строки из нулей и единиц.

Примечание

Пример

Сообщить("" + ИОС.ДесятичноеИзДвоичнойСтроки("10001101"));

ПодключитьВнешнююКомпоненту(ОбъединитьПути(Новый Файл(ТекущийСценарий().Источник).Путь, "OneScriptIntegrator.dll"));
ИОС = Новый ИнтеграторОдноСкрипта();

Сообщить("" + ИОС.ДесятичноеИзДвоичнойСтроки("10001101"));
