Математика.Тау (Math.Tau) Свойство

Использование

Только чтение.

Значение

Тип: Число.

Возвращает количество радианов в одном повороте, указанное константой, приблизительно равное 6.2831853.

Примечание

Пример

Сообщить("Тау = " + ИОС.Математика().Тау);

ПодключитьВнешнююКомпоненту(ОбъединитьПути(Новый Файл(ТекущийСценарий().Источник).Путь, "OneScriptIntegrator.dll"));
ИОС = Новый ИнтеграторОдноСкрипта();

Сообщить("Тау = " + ИОС.Математика().Тау);
