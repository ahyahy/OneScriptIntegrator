ИнтеграторОдноСкрипта.ЗаписатьВесьТекст (OneScriptIntegrator.WriteAllText) Метод

Синтаксис

ЗаписатьВесьТекст(<ПутьДоФайла>, <Текст>)

Параметры

ПутьДоФайла (обязательный)
Тип: Строка.
Путь до файла, в который нужно записать указанный текст.
Текст (обязательный)
Тип: Строка.
Текст, записываемый в файл.

Возвращаемое значение

Описание

Создает новый файл, записывает содержимое в файл, а затем закрывает файл. Если целевой файл уже существует, он усечен и перезаписан.

Примечание

Метод создан для упрощения тестирования библиотеки.

Используется кодировка UTF8.

Пример

ИОС.ЗаписатьВесьТекст(ОбъединитьПути(ИОС.КаталогСценария(ЭтотОбъект), "Текстовый файл.txt"), "Текст для файла");

ПодключитьВнешнююКомпоненту(ОбъединитьПути(Новый Файл(ТекущийСценарий().Источник).Путь, "OneScriptIntegrator.dll"));
ИОС = Новый ИнтеграторОдноСкрипта();
