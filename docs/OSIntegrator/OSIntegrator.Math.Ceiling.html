Математика.НаименьшееЦелое (Math.Ceiling) Метод

Синтаксис

НаименьшееЦелое(<ЧисловойПараметр>)

Параметры

ЧисловойПараметр (обязательный)
Тип: Число.
Десятичное число.

Возвращаемое значение

Тип: Число.

Наименьшее целочисленное значение, которое больше или равно указанному в параметре числу.

Описание

Возвращает наименьшее целочисленное значение, большее или равное указанному десятичному числу.

Примечание

Пример

Сообщить("НаименьшееЦел(3.14) = " + ИОС.Математика().НаименьшееЦелое(3.14));
