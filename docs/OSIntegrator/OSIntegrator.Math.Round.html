Математика.Окр (Math.Round) Метод

Синтаксис

Окр(<ЧисловойПараметр>, <Разрядность>)

Параметры

ЧисловойПараметр (обязательный)
Тип: Число.
Округляемое число.
Разрядность (обязательный)
Тип: Число.
Количество десятичных разрядов в возвращаемом значении.

Возвращаемое значение

Тип: Число.

Округленное число.

Описание

Округляет десятичное значение до указанного числа знаков после запятой; значения посередине округляются до ближайшего четного числа.

Примечание

Пример

Сообщить("Окр(0.568534, 3) = " + ИОС.Математика().Окр(0.568534, 3));
