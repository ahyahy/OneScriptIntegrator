Математика (Math) Свойства

Свойства

Е (E) Представляет основание натурального логарифма e, приблизительно равное 2,718.
Пи (PI) Представляет отношение длины окружности круга к его диаметру, приблизительно равное 3,14159.
Тау (Tau) Возвращает количество радианов в одном повороте, указанное константой, приблизительно равное 6.2831853.
