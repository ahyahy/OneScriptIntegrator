ИнтеграторОдноСкрипта.СлучайноеИмя (OneScriptIntegrator.TempName) Свойство

Использование

Только чтение.

Значение

Тип: Строка.

Возвращает уникальную комбинацию символов для имени временного файла, сформированную на основе GUID.

Примечание

Пример

Сообщить("СлучайноеИмя = " + ИОС.СлучайноеИмя);
Полный пример кода 



ПодключитьВнешнююКомпоненту(ОбъединитьПути(Новый Файл(ТекущийСценарий().Источник).Путь, "OneScriptIntegrator.dll"));
ИОС = Новый ИнтеграторОдноСкрипта();

Сообщить("СлучайноеИмя = " + ИОС.СлучайноеИмя);
Сообщить("СлучайноеИмя = " + ИОС.СлучайноеИмя);
