ИнтеграторОдноСкрипта.ОжидатьКаталог (OneScriptIntegrator.WaitDirectory) Метод

Синтаксис

ОжидатьКаталог(<Путь>, <ВремяОжидания>)

Параметры

Путь (обязательный)
Тип: Строка.
Путь до каталога.
ВремяОжидания (необязательный)
Тип: Число.
Время в миллисекундах на подтверждение наличия каталога на диске. По умолчанию - 10 секунд.

Возвращаемое значение

Тип: Булево.

Возвращает Истина, если наличие каталога подтверждено в течение задержки на ожидание.

Описание

Возвращает результат проверки существования каталога на диске, с задержкой в миллисекундах на ожидание при проверке.

Примечание

Пример

Сообщить("" + ИОС.ОжидатьКаталог("Не существующий путь", 5000));
Полный пример кода 



ПодключитьВнешнююКомпоненту(ОбъединитьПути(Новый Файл(ТекущийСценарий().Источник).Путь, "OneScriptIntegrator.dll"));
ИОС = Новый ИнтеграторОдноСкрипта();

Сообщить("Проверяем наличие каталога в течение 5 секунд.");
Сообщить("" + ИОС.ОжидатьКаталог("Не существующий путь", 5000));
