ИнтеграторОдноСкрипта.РазобратьСтроку (OneScriptIntegrator.DisassembleString) Метод

Синтаксис

РазобратьСтроку(<ИсходнаяСтрока>, <Разделитель>)

Параметры

ИсходнаяСтрока (обязательный)
Тип: Строка.
Строка для разбора.
Разделитель (обязательный)
Тип: Число.
Строка, по которой исходная строка будет разделена на подстроки.

Возвращаемое значение

Тип: Массив.

Описание

Возвращает массив с подстроками после разделения исходной строки по разделителю.

Примечание

Пример

М = ИОС.РазобратьСтроку(Стр, "ра");
