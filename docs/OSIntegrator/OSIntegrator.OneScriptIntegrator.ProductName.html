ИнтеграторОдноСкрипта.ИмяПродукта (OneScriptIntegrator.ProductName) Свойство

Использование

Только чтение.

Значение

Тип: Строка.

Возвращает имя продукта, связанное с этим приложением.

Примечание

Пример

Сообщить("ИмяПродукта = " + ИОС.ИмяПродукта);
Полный пример кода 



ПодключитьВнешнююКомпоненту(ОбъединитьПути(Новый Файл(ТекущийСценарий().Источник).Путь, "OneScriptIntegrator.dll"));
ИОС = Новый ИнтеграторОдноСкрипта();

Сообщить("ИмяПродукта = " + ИОС.ИмяПродукта);
