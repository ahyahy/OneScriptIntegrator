НаблюдательФайловойСистемы.КомпонентДоступен (FileSystemWatcher.EnableRaisingEvents) Свойство

Использование

Чтение и запись.

Значение

Тип: Булево.

Возвращает или задает значение, определяющее, доступен ли данный компонент. Истина - компонент доступен, Ложь - в противном случае. Значение по умолчанию: Ложь.

Примечание

Компонент не будет вызывать события, если не задать свойству КомпонентДоступен (EnableRaisingEvents) значение Истина. Компонент не будет отслеживать указанный каталог пока свойство Путь (Path) не будет задано и свойство КомпонентДоступен (EnableRaisingEvents) не будет установлено в значение Истина.

Пример

НаблюдательФайловойСистемы1.КомпонентДоступен = Истина;
