Кодировка.ПолучитьСтроку (Encoding.GetString) Метод

Синтаксис

ПолучитьСтроку(<БайтМассив>)

Параметры

БайтМассив (обязательный)
Тип: Массив.
Массив байтов для декодирования.

Возвращаемое значение

Тип: Строка.

Строка, содержащая декодированное представление указанного массива байтов.

Описание

Возвращает строку, содержащую все декодированные байты из указанного массива байтов.

Примечание

Байтовые значения переводятся в целые числа.

При преобразовании массива байтов, с использованием кодировки, полученной через свойство ПоУмолчанию (ByDefault), и получением после этого строкового значения, в конце строки может быть добавлено несколько символов.

Эти символы будут соответствовать коду 9702 в кодировке Unicode (Прозрачный маркер списка).

Пример

Кодировка1 = ИОС.Кодировка.Юникод;
Массив = Кодировка1.ПолучитьБайты("Откуда мне знать?");
Сообщить("ПолучитьСтроку = " + Кодировка1.ПолучитьСтроку(Массив));
