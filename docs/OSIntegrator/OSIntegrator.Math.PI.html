Математика.Пи (Math.PI) Свойство

Использование

Только чтение.

Значение

Тип: Число.

Представляет отношение длины окружности круга к его диаметру, приблизительно равное 3,14159.

Примечание

Пример

Сообщить("Пи = " + ИОС.Математика().Пи);

ИОС = Новый ИнтеграторОдноСкрипта();
